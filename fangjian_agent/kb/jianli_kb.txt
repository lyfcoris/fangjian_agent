【检索片段】演示教材《建筑施工技术与质量验收》第6章 P120（占位条目，待替换）
主题标签：后浇带 / 施工缝 / 封闭时间
后浇带应按设计要求的位置和宽度留置。后浇带两侧施工缝属结构薄弱环节，封闭前应清理浮浆、松动骨料与杂物，并充分湿润基面。后浇带混凝土的封闭时间与所用材料强度等级应符合设计要求，不得提前封闭。封闭后应及时养护，养护期内不得提前加载或扰动。

【检索片段】演示教材《建筑施工技术与质量验收》第6章 P125（占位条目，待替换）
主题标签：渗漏 / 接茬 / 注浆封堵
混凝土结构出现渗漏水时，应先查明水源与渗漏路径，不得仅做表面封闭。对施工缝、裂缝等渗漏部位，可采用注浆或封堵处理，材料与工艺应符合方案要求。处理后应做淋水或蓄水试验检查效果，并持续观察，确认无渗漏后办理复查闭合。

【检索片段】演示教材《建筑施工技术与质量验收》第6章 P118（占位条目，待替换）
主题标签：混凝土养护 / 保湿 / 养护时间
混凝土浇筑完成后应及时覆盖并保湿养护，养护时间及方式应符合施工方案与相关验收要求。高温、大风或干燥天气应加强保湿，防止失水过快产生收缩裂缝。后浇带、施工缝及大体积混凝土等部位应重点养护。

【检索片段】演示教材《建筑施工技术与质量验收》第6章 P115（占位条目，待替换）
主题标签：施工缝 / 接茬 / 凿毛
施工缝位置应设置在受剪力较小且便于施工的部位，并应符合设计要求。继续浇筑前，应对施工缝表面凿毛，清除浮浆、松动石子与杂物并充分湿润，铺设与混凝土成分相近的水泥砂浆后再浇筑，确保新旧混凝土结合紧密。

【检索片段】演示教材《建筑施工技术与质量验收》第7章 P140（占位条目，待替换）
主题标签：填充墙 / 拉结筋 / 植筋
填充墙与混凝土柱、墙交接处应按设计要求设置拉结筋，拉结筋的间距、伸入墙内长度及锚固方式应符合设计与构造要求，砌筑时不得漏放、错位或弯折损伤。对已漏设部位，应办理工程洽商，采取植筋或加设拉结等加强连接措施，并经隐蔽验收确认。

【检索片段】演示教材《建筑施工技术与质量验收》第7章 P142（占位条目，待替换）
主题标签：填充墙 / 顶部斜砌 / 沉实
填充墙砌至接近梁、板底时，应预留空隙，待墙体砌筑完成并沉实稳定后，再用斜砌砖或专用填塞材料将顶部空隙逐块顶紧，不得一次砌平，不得用砂浆干塞或碎砖随意填塞。

【检索片段】演示教材《建筑施工技术与质量验收》第8章 P160（占位条目，待替换）
主题标签：混凝土外观缺陷 / 蜂窝 / 麻面 / 露筋
混凝土结构构件的外观质量不应有影响结构性能或使用功能的缺陷。蜂窝、麻面、露筋、孔洞、夹渣等外观缺陷，应结合构件受力状态、钢筋保护层厚度及所处环境评定其严重程度，并按要求处理。

【检索片段】演示教材《建筑施工技术与质量验收》第8章 P165（占位条目，待替换）
主题标签：缺陷处理 / 修补方案 / 报审
构件出现外观质量缺陷时，施工单位不得擅自修补。应先查明原因并评定影响程度，编制缺陷处理方案。影响结构性能或使用功能的重要缺陷，其处理方案应报监理单位审查，必要时经原设计单位认可后实施。处理完成后应复查验收，并留存处理与复查记录。

【检索片段】演示教材《建筑施工技术与质量验收》第8章 P158（占位条目，待替换）
主题标签：混凝土浇筑 / 振捣 / 保护层
混凝土浇筑应分层进行并充分振捣，振捣间距与时间应适宜，避免漏振、欠振形成蜂窝麻面。钢筋密集部位应调整振捣方式并加强观察；钢筋保护层垫块应安放到位、固定可靠，防止浇筑过程中偏移造成露筋。

【检索片段】演示教材《建筑施工技术与质量验收》第9章 P180（占位条目，待替换）
主题标签：抹灰 / 基层处理 / 挂网
抹灰施工前，基层表面的灰尘、污垢、油渍及松散层应清理干净并洒水湿润。混凝土与砌体等不同材料基体交接处，应采取挂网等加强措施，防止因材料收缩差异产生开裂。

【检索片段】演示教材《建筑施工技术与质量验收》第9章 P182（占位条目，待替换）
主题标签：抹灰 / 分层 / 空鼓开裂防治
抹灰应分层进行，每层抹灰厚度应适宜，并待前一层凝结硬化后再抹后一层，严禁一次抹灰过厚。各抹灰层之间及抹灰层与基层之间应粘结牢固，无脱层、空鼓、面层无爆灰和裂缝等缺陷。

【检索片段】演示教材《建筑施工技术与质量验收》第9章 P185（占位条目，待替换）
主题标签：空鼓 / 开裂 / 返工处理
抹灰层已出现空鼓、开裂的，应查明范围并做好标记，将空鼓部位铲除清理干净后，按基层处理与分层抹灰的要求重新施工，严禁仅在表面涂饰掩盖。修复完成后应复查空鼓情况，确认合格并记录闭合。

电焊工、气割工配备劳动防护用品应符合下列规定：

【检索片段】《建筑与市政施工现场安全卫生与职业健康通用规范》GB 55034-2022 第6.0.13条
主题标签：职业健康管理 / 职业病危害因素 / 职业健康检查
其他特殊环境作业的人员配备劳动防护用品应符合下列规定：
1  在噪声环境下工作的人员应配备耳塞、耳罩或防噪声帽等；
2  进行地下管道、井、池等检查、检修作业时，应配备防毒面具、防滑鞋和手套；
3  在有毒、有害环境中工作的人员应配备防毒面罩或面具；
4  冬期施工期间或作业环境温度较低时，应为作业人员配备防寒类防护用品；
5  雨期施王期间，应为室外作业人员配备雨衣、雨鞋等个人防护用品。
