# 生成监理通知单（jianli-notice）

模板文件：`<PROJECT_DIR>\templates\监理通知单.md`
（`install.py` 安装时已把上面的占位符替换为本机实际路径）

## 何时使用
用户已给出现场隐患/质量问题描述，并要求"出监理通知单 / 整改通知单 / 发通知单"时。
（默认情况下 Agent 输出固定三段；只有用户明确要通知单时，才用本模板。）

## 生成步骤
1. 先用 jianli-kb-retrieval 技能检索规范，形成三段结论（问题归纳 / 规范依据 / 监理整改意见）；
2. 按模板填写：
   - **工程名称**：用户提供了就填；没给则写"（请补充工程名称）"；
   - **编号**：当天日期 + 两位序号，如 `2026-09-16-01`（多次签发依次递增）；
   - **致**：施工单位名称；没给则写"（施工单位）"并请用户补充；
   - **事由**：一句话概括问题（来自【问题归纳】）；
   - **内容**：分条写整改要求（来自【监理整改意见】的 ①措施 ②复查标准 ③闭环时限）；末尾另起一行写"依据："并列出规范条文，格式《规范全称》GB ×××××-×××× 第×.×.×条——**只写检索片段里命中的条文**，没命中就不写依据，并明确提示"知识库未检索到直接适用条文，需补充依据后签发"；
   - **签字/日期**：留空待签；
3. 全文用工地书面语、分条编号，不写空话套话。

## 输出契约
- 严格用模板结构（工程名称→致→事由→内容→监理工程师签字→总监理工程师签字→签收意见）；
- 引用的条文必须能通过 `evals\cite_check.py` 回查（只能来自知识库）；
- 若输入信息不足（工程名称、施工单位缺失），如实标注待补充，不得臆造。
